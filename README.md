## 🎯 Цели и архитектура проекта

Проект посвящён исследованию влияния внедрения искусственного интеллекта и макроэкономических факторов на рынок труда в IT-секторе (2025–2026), а также практической разработке кастомных структур данных и алгоритмов.

Кодовая база полностью переписана на **чистый Python 3.10** (с сохранением веб-визуализатора на TypeScript / React).

### Структура проекта в директории `python/`:

| Файл | Описание |
| :--- | :--- |
| `my_hash_map.py` | Реализация собственной Hash Table (Separate Chaining + djb2 + динамический rehash при $\alpha > 0.75$) |
| `dataset.py` | Dataclass `LayoffRecord`, детерминированный генератор данных LCG (от 1 000 до 100 000+ записей), CSV парсер и экспорт |
| `benchmark.py` | Сравнительный эксперимент (Шаг 8) между $O(N)$ (линейный поиск) и $O(1)$ (`MyHashMap.get`) |
| `main.py` | Главная консольная точка входа для демонстрации всех этапов работы |
| `test_hash_map.py` | Модульные тесты `unittest` (8 тестов, 100% pass) |
| `Tech_Layoffs_Algorithmic_Engine_ITIS.ipynb` | Готовый Jupyter / Google Colab ноутбук с формулами, разметкой и кодом для сдачи |

## 📊 Результаты бенчмарка (Шаг 8)

При тестировании 30 равномерно распределенных запросов:

- **10 000 строк:**
  - Линейный поиск $O(N)$: **81.68 ms** (ср. 2,722.72 μs)
  - `MyHashMap` $O(1)$: **0.186 ms** (ср. 6.19 μs)
  - **Ускорение:** **440.0x**

- **100 000 строк:**
  - Линейный поиск $O(N)$: **849.87 ms** (ср. 28,329.10 μs)
  - `MyHashMap` $O(1)$: **0.153 ms** (ср. 5.10 μs)
  - **Ускорение:** **5,554.7x**
  - При 262,144 корзинах самая длинная цепочка коллизий составила всего **4 пары**, средняя глубина занятой корзины — **1.19**.
